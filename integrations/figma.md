# Figma Integration

Figma is optional. The host adapter is responsible for discovering/invoking its Figma capability. The core must not depend on a specific MCP server, connector name or vendor API.

Setup: detect access; request authorization through the host; never store credentials; validate a user-selected file; determine readable information; report unsupported data as unknown; fall back to screenshots/images or PDF.

When sufficient information exists, construct a verified graph of states and transitions. It may resolve available next states but must not reveal the intended path to the simulated persona.
