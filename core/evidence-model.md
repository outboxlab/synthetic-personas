# Evidence Model

Classify meaningful findings as:
1. **Provided evidence** — directly visible or explicitly supplied.
2. **Synthetic behavior** — action/reaction simulated for a persona.
3. **Interpretation** — reasoned reading of behavior.
4. **Hypothesis** — proposition requiring validation.
5. **Recommendation** — design/research action.
6. **Limitation / unknown** — unavailable or unsupported information.

Never collapse these categories into a single claim.

Recommended finding format: Finding; Source/category; Personas affected; Journey/state; Confidence in interpretation; Why it matters; Suggested next validation.
