# Methodology

## Stage 1 — Free exploration
No mission and no explanation of the intended information architecture. Observe first attention, spontaneous actions, perceived hierarchy, expectations, doubts and elements interpreted as interactive.

## Stage 2 — Mental model
Explore how the persona describes the product, where it expects functions to live, distinctions between areas, and what it expects after interacting with key elements.

## Stage 3 — Missions
Run neutral, persona-relevant tasks. Record choices, detours, uncertainty, inferred labels, expected outcomes and blockers.

## Stage 4 — Consolidation
Consolidate positive signals, attention points, differences between personas, recommendations and questions requiring real-user validation.

## Journey testing
When a navigable graph can be verified, use it to resolve available next states without exposing the intended route. If a transition is unknown, mark it unknown instead of inventing it.
