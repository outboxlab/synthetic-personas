# Capability Detection

Relevant capabilities may include text reasoning, vision, file/PDF reading, web access, Figma/design-tool integration, browser/navigation, persistent workspace/memory, and external tools/connectors.

Status: AVAILABLE, AVAILABLE WITH AUTHORIZATION, UNAVAILABLE, NOT CHECKED.

Do not claim a capability until verified when verification is possible. Missing optional capabilities must not block the protocol when a fallback exists.

Design-source fallback: connected design source → screenshots/images → PDF → user-described transitions.
