# Synthetic Personas Protocol

## Purpose
Provide a repeatable, transparent method for AI-assisted synthetic usability testing across different LLMs and agent environments.

## Lifecycle
SETUP → BRIEF → MATERIALS → PERSONAS → HYPOTHESES → MISSIONS → PLAN → RUN → SYNTHESIZE → REPORT → LEARN

## Test fidelity
Classify material before evaluation: Concept, Journey / information architecture, Low-fidelity wireframe, Interactive prototype, or High-fidelity prototype. Evaluation criteria must match fidelity.

## Test sequence
1. Free exploration without mission or priming.
2. Mental-model investigation.
3. Persona-specific missions.
4. Consolidation across personas.
5. Findings, uncertainties and recommendations.

## Guardrails
A synthetic test generates directional hypotheses and simulated reactions. It does not establish prevalence, statistical confidence, real-user satisfaction, conversion impact, accessibility compliance, or empirical behavioral truth unless supported by separate real evidence.

## Cross-platform contract
Adapters may change tool invocation, file access and integration setup. They may not change methodological invariants.
